🔐 Authentication & Authorization API

A backend project built with Node.js, Express.js, MongoDB, and Mongoose to practice implementing authentication and authorization in a REST API.

This project is part of my backend development learning journey, where I'm learning how to structure backend applications using an MVC-style architecture.

🛠️ Technologies Used

- Node.js
- Express.js
- MongoDB
- Mongoose
- bcryptjs
- dotenv
- Morgan

📁 Project Structure

src/
├── config/
├── controllers/
├── models/
└── routes/

Config

Contains configuration-related files, including the database connection.

Controllers

Contains the application logic for handling requests and responses.

Models

Contains the MongoDB/Mongoose data models.

Routes

Contains the API route definitions.

🎯 Project Goals

The main goals of this project are to practice:

- Building REST APIs with Express.js
- Connecting an Express application to MongoDB
- Working with Mongoose
- Structuring a backend application using MVC principles
- Implementing authentication concepts
- Implementing authorization concepts
- Organizing backend code into separate responsibilities

🚀 Getting Started

1. Clone the repository

git clone https://github.com/OFFICIALBAM0430/BalogunMoses-Authorization-and-Authentication.git

2. Install dependencies

npm install

3. Configure environment variables

Create a ".env" file and add the environment variables required by the application.

4. Start the application

For development:

npm run dev
